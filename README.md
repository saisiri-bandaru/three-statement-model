# Three-statement model

Linked annual statements for a fictional company (**Northline Consumer Products**).

**File to open:** `Northline_Three_Statement_Model.xlsx`

If that file is not in the repo yet, download it from the conversation and use **Add file → Upload files**.

## What you will see

- Income statement (revenue through net income)
- Balance sheet (working capital, PP&E, debt, equity)
- Cash flow statement (operations, investing, financing)
- A check that cash on the balance sheet equals cash on the cash flow statement

Yellow cells = inputs. Black = formulas.

## Why this belongs on an FP&A profile

It shows the statements are not three separate files. Change revenue or capex and cash and the balance sheet should still tie.

All numbers are made up.
